คู่มือการใช้งาน (Quick User Guide)

ยินดีต้อนรับสู่ ET OPC Company AI Workspace แพลตฟอร์มผู้ช่วยอัจฉริยะสำหรับองค์กร

🔑 วิธีการขอและตั้งค่า API Key (สำหรับ Admin)

1. ไปที่ Google AI Studio ↗ แล้วกดสร้าง Create API Key ฟรี (ไม่ต้องผูกบัตรเครดิต)
2. คัดลอก API Key ที่ได้ แล้วมาเปิดเมนู "ตั้งค่า AI & Model" ด้านล่างซ้าย
3. เลือก Google Gemini (3.X) เลือกรุ่น Gemini 3.6 Flash แล้ววางคีย์ลงในช่อง
4. กด "🧪 ทดสอบเชื่อมต่อ" และ "💾 บันทึกและเปิดใช้งาน" ระบบพร้อมทำงานทันที!

🔒 1. นโยบายความเป็นส่วนตัวและการคุ้มครองข้อมูล (Privacy Policy)

ระบบ ET OPC Company ให้ความสำคัญสูงสุดต่อการรักษาความปลอดภัยของข้อมูล:

  • ไม่นำข้อมูลไปฝึกโมเดลสาธารณะ (Zero Data Training Policy): ไฟล์เอกสาร เรซูเม่ (CV) และข้อความจะไม่ถูกนำไปใช้เทรนโมเดล AI ภายนอก
  • การจัดเก็บข้อมูลส่วนบุคคล: ข้อมูลประวัติการแชทและการตั้งค่าจะถูกจัดเก็บเฉพาะในเซสชันของผู้ใช้ที่ได้รับอนุญาตเท่านั้น

🤖 2. ข้อกำหนดการใช้งาน AI และการประมวลผล (AI Usage Terms)

ข้อกำหนดสำหรับการใช้งาน AI Agent และระบบอัตโนมัติ:

  • การตรวจสอบความถูกต้อง (Human-in-the-Loop): ผลลัพธ์จากการประเมินเรซูเม่และสรุปงานมีไว้เพื่อสนับสนุนการตัดสินใจ ควรได้รับการตรวจสอบโดยบุคลากรก่อนนำไปใช้งานทางการ
  • ความรับผิดชอบของไฟล์แนบ: ผู้ใช้งานต้องมั่นใจว่าไฟล์ที่อัปโหลดเป็นไปตามนโยบายและระเบียบขององค์กร

👥 3. สิทธิ์การใช้งานและการควบคุมระบบ (Access & Compliance)

สิทธิ์การเข้าถึงเป็นไปตามบทบาทที่ได้รับมอบหมายในสังกัดคณะวิศวกรรมศาสตร์และเทคโนโลยี (ET) สถาบันการจัดการปัญญาภิวัฒน์

📝 ใบบันทึกคะแนนสัมภาษณ์งาน (Interviewer Scorecard)

บันทึกคะแนนและข้อคิดเห็นจากการสัมภาษณ์จริงเพื่อนำไปประมวลผลร่วมกับ AI

2. การสื่อสารและทัศนคติ (Communication & Attitude) 22 / 25
3. การแก้ปัญหาและการคิดวิเคราะห์ (Problem Solving) 17 / 20
4. ความเข้ากันได้กับองค์กร (Culture Fit & Teamwork) 18 / 20
